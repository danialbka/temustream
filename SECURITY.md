# Security and privacy

Do not attach or commit IPAs, signed apps, dylibs built with personal signing
material, provisioning profiles, certificates, Apple or Stremio credentials,
device identifiers, application containers, console logs, or playback history.

The repository intentionally ignores all generated artifacts. Before reporting
a bug, reproduce it with legal test media and remove account, device, signing,
stream URL, add-on, and network identifiers from any diagnostic excerpt.
