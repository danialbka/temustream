# Support

Use GitHub Issues for reproducible bugs and feature requests. Include the
platform, OS version, app version, player choice, and the command or screen that
failed. A short sanitized log excerpt is more useful than an entire device log.

This is a community project. There is no guaranteed response time, App Store
availability, hosted streaming service, or support for third-party add-ons.
Questions about a provider's account, content, availability, or terms belong
with that provider.

Do not use a public support issue for a suspected vulnerability or anything
containing credentials, tokens, private URLs, device identifiers, or personal
data. Follow [SECURITY.md](SECURITY.md) instead.
